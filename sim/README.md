# sim/

Planned location for an offline simulator/replay tool that emits synthetic
telemetry, map-delta, survivor-detection, and video data matching the
Drone ↔ GCS interface (`../docs/DATA_MODELS.md`), so the GCS can be
developed and tested without drone hardware or arena access. See
`../docs/ARCHITECTURE.md` §6.

**Phase 0: empty.** No implementation yet.
